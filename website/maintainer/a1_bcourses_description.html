Assignment 1 (due Monday, July 27 at 5:00pm)

A short solo warm-up, and the first step of a thread you carry through Assignment 2 and your final group project. Pick a county, set of counties, or region you care about. You will keep working with this same area all term.

The task

  1. Use get_acs() to pull one ACS variable that says something about housing precarity (rent burden, median rent, the share of households that rent, race/ethnic concentrations, etc.).
  2. Make one chart of it. A bar chart across your counties works well or a histogram across a distribution within a county.
  3. Write a short paragraph (minimum 2–3 sentences) describing what the chart shows and anything that surprised you. Keep it simple. No bibliography or ASA formatting yet. Maybe speak to what this might mean for that population or area. You can write as much as you want but I need you to interpret the plot like you’re describing it to someone.

What you will turn in: exactly two files

  1. Your R script, named a1_[yourlastname].R, a fresh file you write yourself. We’ll go over this in class on July 23rd
  2. A Word document (or PDF) with your chart image pasted in and your writeup under it.

How to save an R script and submit it

Step 1. Study the model answer, then close it

The class repo contains a complete example, code/a1_example.R. Read it top to bottom and run it — it shows the shape of a finished submission. Then close it and build your own. The example is a model, not a template. Your submission must be a fresh script about your place, with your variable and your sentences; your graders know the example line by line. Borrowing its structure (pull, chart, save, sentences) is exactly what it is for.

Step 2. Create a NEW script in your Home folder (first time doing this, so here is the whole move)

File > New File > R Script. Write your assignment there, starting with the two library() lines like every lab. File > Save, named a1_[yourlastname].R (Tim’s is a1_thomas.R), to your Home folder — and here is the warning that matters: do NOT save your work inside the SOC-N100-Housing-Precarity-2026 class folder. That folder is managed by the course’s git repository and updates every time you click the class RStudio link; anything you add there is likely to be overwritten or lost. Your Home folder (the house icon) is safe. End your script with ggsave("~/a1_[yourlastname].png", width = 8, height = 5) to save the plot you made. Then the one test that matters: Session > Restart R, run it top to bottom — if it runs clean on the DataHub, it runs for the grader.

Step 3. Download to your computer

The DataHub cannot submit to bCourses for you, so the path is download, then upload. Go to the Files pane → house icon → check the box next to your .R script you edited and saved → More (gear icon) > Export; repeat for the .png.

Step 4. Build your write-up document

Paste the chart image into Word or Google Docs, write your minimum 2–3 sentences under it (describe first, then interpret), add your AI share links near the sentences, save as .docx or PDF (Google Docs: File > Download > PDF).

Step 5. Upload both files

Start Assignment → File Upload → Choose File (your .R) → + Add Another File (your write-up) → Submit Assignment; the timestamp confirmation is your receipt.
