Learn R

Everything on this page is free and was link-checked in July 2026. You do not need all of it. Pick one track that fits how you like to learn, and treat the rest as reference. The labs themselves assume zero background — these resources are for practice between labs and for going deeper.

Start with the course materials

  • The course R cheat sheet — code/r_functions_cheatsheet.R, already on your DataHub (open it from the Files pane, same as a lab; browse it on GitHub). Every function our labs use, one line and one example each, grouped by task and tagged with the lab where you first meet it. Ctrl-F it whenever a lab line looks unfamiliar.
  • Analyzing US Census Data (Kyle Walker) — our course reference text, free to read online. The assigned chapters walk through exactly the tools we use in lab: tidycensus (Ch 1–2), wrangling Census data with the tidyverse (Ch 3–4), and Census geography and mapping (Ch 5–6).
  • Posit cheatsheets — one-page references for the tools we use constantly. Copies of the most useful ones (data visualization, data transformation, data import, R best practices, Quarto) live in the class repo’s docs/cheatsheets folder, so they are already on your DataHub.

If you have never coded before

  • Hands-On Programming with R (Garrett Grolemund) — a full book written explicitly for non-programmers, free online. The gentlest complete introduction to R itself: objects, functions, and how to think in code. Chapters 1–3 pair well with our Labs 1–2.

Practice inside R (interactive)

  • swirl — a free package that teaches R inside the R console, at your own pace. Works on the DataHub. Three lines to start:

    install.packages("swirl")   # once
library(swirl)              # each session
swirl()                     # follow the prompts

Go deeper on the tidyverse

  • R for Data Science, 2nd ed. (Wickham, Çetinkaya-Rundel & Grolemund) — the standard free book on the tidyverse workflow we teach: transform, visualize, model, communicate. One heads-up: this book writes the pipe as |> (R’s newer built-in pipe). It works the same way as the %>% we use in lab — read them as the same word, “and then.”

A guided lesson series

  • Software Carpentry: Programming with R — a classic free lesson sequence built around a patient-data example. The datasets it uses are already in the class repo under data/software_carpentry/, so you can follow along on the DataHub without downloading anything.

Prefer a structured course with videos?

  • Data Science: R Basics (HarvardX / edX, Rafael Irizarry) — self-paced, introductory, about 1–2 hours a week, and free to audit (ignore the optional paid certificate).

On campus

  • UC Berkeley D-Lab — free workshops and consulting for enrolled Berkeley students; their catalog regularly includes introductory R sessions, and their front desk (dlab-frontdesk@berkeley.edu) can point you to the next one.

How to actually get better

Twenty minutes of practice a few times a week beats a three-hour binge. The single highest-value habit: re-open a lab script, change one small thing, and predict what will happen before you run it. And when you hit an error, use it — read it out loud, then ask your AI assistant to explain it before fixing it (keep the share link if it touches assignment work; see the AI policy).
